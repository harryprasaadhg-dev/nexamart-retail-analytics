# Project Charter

## Project Name
NexaMart Retail Business Intelligence and
Operations Analytics System

## Business Background
NexaMart is a fictional Indian omnichannel
retail company operating through physical
stores and online sales channels.

## Project Objective
To develop an integrated analytics solution
that helps management monitor business
performance and make data-driven decisions.

## Project Scope
1. Sales and profitability analysis
2. Inventory analysis
3. Customer analysis
4. Operations analysis
5. Management reporting

## Tools
- MySQL
- Python
- Microsoft Excel
- Power BI

## Expected Outcome
An end-to-end retail analytics portfolio
project with business documentation,
SQL analysis, Python data processing,
Excel reporting and Power BI dashboards.

## Data Disclaimer
All company data used in this project will
be simulated for educational and portfolio
purposes.
